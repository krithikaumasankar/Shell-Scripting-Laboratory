## 🧠 Repository Overview

**Shell-Scripting-Laboratory** is a structured collection of shell programming exercises developed as part of the **Linux Administration Laboratory – Experiment 11**.

This repository focuses on fundamental shell programming concepts such as:

* Variables and user input
* Arithmetic and relational operators
* Conditional decision-making
* Looping constructs
* Mathematical computations
* Number processing
* Pattern generation
* Basic problem-solving

The programs are designed to provide practical experience with command-line programming and strengthen logical thinking through simple computational tasks.

## 🚀 Getting Started

### Clone the Repository

    git clone https://github.com/krithikaumasankar/Shell-Scripting-Laboratory.git

### Navigate to the Repository

    cd Shell-Scripting-Laboratory

### Give Execution Permission

For example:

    chmod +x 01-Number-Swap.sh

### Run a Program

    ./01-Number-Swap.sh

The same approach can be used to execute the other `.sh` programs.
